# Goal sentences with a deadline

In the model solution of the task `aufgabe-mein-plan`, the example goal
«Ziel: Ich kann bis zum Mathetest am 28. alle Aufgabentypen der
Prozentrechnung ohne Hilfe lösen.» describes a state that will be
reached BY a deadline. After "By <deadline>", use the future:
"Goal: By the maths test on the 28th, I will be able to solve all types
of percentage problems without help." (not "I can solve").
