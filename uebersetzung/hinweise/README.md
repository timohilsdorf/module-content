# Korrekturhinweise je Modul und Sprache

Eine Datei `<slug>.<lang>.md` je Fassung – das dauerhafte
Korrektur-Gedächtnis: Gemeldete Übersetzungsfehler werden hier als
Anweisung festgehalten («Das Fachwort X immer als Y übersetzen») und
fliessen in JEDE künftige Neuerzeugung ein. Eine Änderung an einer
Hinweis-Datei markiert die zugehörige Fassung automatisch als
VERALTET (hintsHash) und löst bei der Nachführung bewusst eine
Voll-Neuerzeugung aus. Wiederkehrende, modulunabhängige Begriffe
gehören stattdessen ins Glossar (uebersetzung/glossar.<lang>.json).
